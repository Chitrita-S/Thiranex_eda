# Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project performs Exploratory Data Analysis on the **Titanic dataset** to identify patterns, relationships, and trends using statistical analysis and data visualization.

## 🎯 Objectives

* Analyze and understand the dataset
* Identify missing values and duplicates
* Explore relationships between variables
* Analyze factors associated with passenger survival
* Generate meaningful visualizations and insights

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## 📊 Analysis Performed

* Statistical Summary
* Missing Value Analysis
* Survival Analysis
* Gender & Passenger Class Analysis
* Age & Fare Analysis
* Family Size Analysis
* Correlation Analysis
* Data Visualization

## 📈 Visualizations

The project includes:

* Survival Distribution
* Survival Rate by Gender
* Survival Rate by Passenger Class
* Age & Fare Analysis
* Family Size vs Survival
* Correlation Heatmap

## ▶️ How to Run

```bash
py -m pip install pandas numpy matplotlib seaborn
py eda_analysis.py
```

## 🎓 Learning Outcome

Developed practical skills in **Exploratory Data Analysis, statistical analysis, data visualization, correlation analysis, and data storytelling**.
